Тема: Створення веб-сторінок за допомогою HTML5

Мета: Ознайомитися з підходами та технологіями, що використовуються для розмітки сучасних веб-сторінок, та розмітити веб-сторінку з допомогою мови розмітки HTML5. Навчитися створювати різні структури веб-сторінок використовуючи HTML5.
